# weatherVERT
погодна станція, календар, годинник,  мапа тривог, журнал тривог та сповіщення про тривоги. веб інтерфейс налаштувань
зібрано за допомогою esp32 wroom, екрану 2.8 дюймів tft, ili 9341, біпер звичайний та трьохконтактний світлодіод. датчик світла для автояскравості.
пр першому вмикання треба обрати мережу до якої підключатись, токени для відображення погоди та тривог, з сайтів OpenWeather, alerts.in.ua,  ukrainealarm.com
підключення пінів вказано в коді та вкладках проекту.
необхідні бібліотеки: Adafruit GFX, Adafruit ILI9341, U8g2_for_Adafruit_GFX,
//             XPT2046_Touchscreen (Paul Stoffregen), Time (TimeLib),
//             WiFiManager (tzapu), ArduinoJson, QR-код ESP-IDF з ESP32 core
 1) ДАТЧИК СВІТЛА (фоторезистор GL5528 або подібний) — GPIO34
//        3.3V ──[ фоторезистор ]──┬── GPIO34
//                                 └──[ резистор 10 кОм ]── GND
//     (за бажанням конденсатор 100 нФ між GPIO34 і GND — менше шуму)
//     У налаштуваннях на сторінці телефона потім увімкніть "Автояскравість".
//
//  2) ДВОКОЛІРНИЙ СВІТЛОДІОД (червоний + зелений, 3 виводи) — GPIO27 і GPIO32
//        ЗАГАЛЬНИЙ вивід (зазвичай середній) ──────────────── GND
//        вивід "червоний" ── GPIO27
//        вивід "зелений"  ── GPIO32 ( в мене резистор один на 0.5кОм на середній нозі для зменшення струму)
//     Якщо діод "із загальним анодом" (світиться, коли загальний вивід на +3.3V, а решта через
//     резистори на GND), загальний вивід підключіть до 3.3V і поставте LED_COMMON_ANODE 1 у скетчі.
//     Логіка: тривога — червоний (блимає/світить), спокійно — зелений, жовтий рівень — обидва
//     (жовтий/бурштиновий), немає даних — вимкнено. Вночі зелений приглушується
